# Superstore Sales Analysis

## Overview
SQL and Excel analysis of 4,922 US retail sales records (2015–2018).
Tools used: SQLite, Microsoft Excel

## Key Findings
- **West region** leads revenue at $204,057 (30% of total)
- **Office Supplies** is the top category at $228,818
- Only **28% of orders** (1,386) exceed the average sale value of ~$128
- **South region** is consistently the weakest across all metrics
- **Technology** drives the highest individual order values (up to $999.98)

## Queries Included
1. Total sales by region
2. Total sales by category
3. Order count by region
4. Top 5 highest value orders
5. Orders above average sale value (subquery)
6. Regional sales ranking (window function)
